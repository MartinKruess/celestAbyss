# Gemeinsame Kreaturenskills

Tamen, Bindung, Kontrolle, Beschwören, Zurückrufen und Zucht werden einmal gemeinsam ausgearbeitet und zählen weiterhin zur Gesamtanzahl jeder Klasse. Geplant für alle Klassen; in den aktuellen Datenbankzuordnungen fehlen Schurke und Schattenkrieger noch bei diesen sechs Skills. Keine Zuordnungsänderung vorgenommen.
