# Luminet / Lichtmagier vor dem Kampf

Level 60, ursprüngliche R6-Rüstung und Magiewaffe, maximal gelernte permanente Passive. Keine aktiven Buffs, Schmuck, Steine oder Begleiterwerte. Intelligenz wird mit 1,8 M-Angriff je Punkt gerechnet. Faith und Victim werden ohne bestätigte klassenabhängige Anwendung nicht zusätzlich zum Intelligenzbeitrag addiert. Die noch offene Agilitätsumrechnung und Waffen-Speed sind ausgeschlossen.

| Wert | Nur Ausrüstung | Mit permanenten Passiven |
| --- | ---: | ---: |
| Leben | 3.541 | 4.141 |
| Mana | 3.827 | 5.867 |
| P-Angriff | 4 | 104 |
| M-Angriff | 708,02 | 948,8 |
| P-Defense | 548 | 728 |
| M-Defense | 796 | 1.072 |

Direkter Attack-Speed-Bonus aus permanenten Passiven: 20 Prozentpunkte. Dies ist keine vollständige Angriffsfrequenz.
