# Physische Rüstungsprogression ohne Skills

Nur Analyse; keine Spielwerte geändert. Klassenbasis + (Level − 1) × aktueller Vita-Abwehrfaktor + fünf Rüstungsteile auf +0. Keine Waffen/Schild, Passiven, Buffs, Zufallswerte, Verstärkungen oder Steine. Bestehende operative Startwerte werden einmal angesetzt; unbekannte Startattribute werden nicht zusätzlich erfunden.

Pro Klasse: X = Gesamtabwehr auf Level 40 mit R3 / 40. Rüstungslevel = Gesamtabwehr / X. Die Levelzuordnung ist die gewünschte Testannahme, keine in den Rüstungsdaten gespeicherte Levelvoraussetzung.
